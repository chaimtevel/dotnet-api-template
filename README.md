### Environment

This app runs on dotnet 6 so the SDK needs to be installed on the machine before developing/running this app.


This template has the following setup.

1. [Swagger](https://github.com/domaindrivendev/Swashbuckle.AspNetCore) available at https://localhost:5001/swagger/
1. Logging to [Graylog](http://logs.bitbean.dev)
1. SOA wired up using dependency injection.
1. Authentication using either external provider (for now only Google has been built) or any other.
1. Aspnet core identity all wired up with 2fa
1. Ability to generate and authenticate using JWTs or user name/password using ASP.Net Identity.

### Not implemented

This template does not implement details that can vary by project. This includes generating the initial migrations and implementing a way to send set password and 2fa messages.

### Running

In order to run this a `appsettings.Development.json` file should be added with at least the following:

```js

{
  "ConnectionStrings": {
    "DefaultConnection": "some connection string"
  },
  "JwtOptions": {
    "Issuer": "ApiGateway",
    "Audience": "http://localhost:3000",
    "JwtSecret": "SomeSecret",
    "TokenDurationInMinutes": "600" // or whatever value
  },
  "GoogleOptions": {
    "GoogleAppId": "If you're using googe login you can use this to verify that the google token is generated by this app"
  }
}

```
